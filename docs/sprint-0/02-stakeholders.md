# Stakeholder & Persona

| Persona | Peran | Tujuan utama | Titik nyeri | Fitur kunci |
|---|---|---|---|---|
| **Admin Sistem** | Mengelola akses | Keamanan data, onboarding cepat | Hak akses diatur manual | US-01 RBAC, matriks izin |
| **Pembina** | Pengawas kelembagaan | Mengawasi tanpa mengurusi detail | Tidak ada visibilitas riwayat persetujuan | US-04 dashboard, US-05 approval akhir, US-02 (S2) |
| **Ketua Pelaksana** | Pemimpin panitia | Keputusan cepat berbasis data | Progres tiap divisi tidak seragam | US-04 IPMS, review surat |
| **Kepala Divisi** | Pemimpin divisi | Administrasi lancar, beban terbagi | Surat tertahan, tak tahu posisi | US-05 pengajuan, US-03 (S2) |
| **Staff Panitia** | Eksekutor | Tahu tugas & tenggat | Instruksi tercecer di chat | US-06 (S2) |
